# User Guide

## Python Files

| Name | Introduction |
|:---|:---|
| `main_vae.py` | Train VAE to obtain `vae_64.pth` |
| `main_diffusion.py` | Train DDPM or FlowMatching to obtain `diffusion_256.pth`<br/>(Requires the pre-trained `vae_64.pth`) |
| `generate_dataset_for_diffusion.py` | Encode images with VAE in advance,<br/>combine with T5 prompt embeddings,<br/>and output `dataset_for_diffusion.pt` |
| `extract_Unet.py` | Extract only the U-Net model parameters from `diffusion_256.pth`<br/>(The rest are mainly optimizer states) |

---

## Folders

| Name | Introduction |
|:---|:---|
| `VAE_output` | Stores VAE-reconstructed images |
| `DDPM_output` | Stores images generated by the DDPM algorithm |
| `FlowMatching_output` | Stores images generated by the FlowMatching algorithm |
| `src` | Core algorithm implementations |
| `data_processor` | Image preprocessing (relatively complex) |

### src/

| Name | Introduction |

### data_processor/

The `prompt/` folder must contain the T5 model `t5-base-local` (you can change the path if needed).

Run `t5_embedding.py` to generate `prompt_embedding_dictionary_T5.npy`.

Run `dataset_process.py` to convert `prompts.json` and the image folder (1) into `dataset.json`.

Place `dataset.json` and `prompt_embedding_dictionary_T5.npy` in the same directory as `main_diffusion.py` for use by `generate_dataset_for_diffusion.py`.

> The image folders and similar large files are not included in this repository due to their size.
